# ADB Connect for Android

Manage your Android TV and Android devices from your phone over ADB.

## Features

- Connect to Android devices over the network
- Control your TV with a remote interface
- View and export device properties
- Install, launch, stop, disable, and uninstall apps
- Capture and export live device logs
- Generate device bug reports
- Run Android shell commands and view their output

Available features depend on the connected device and its permissions.

## Download

Download the signed APK from the Releases page:

https://github.com/siavash2006-lab/ADB-Connect-Android/releases

Android debugging must be enabled on the target device.
Authorize the connection on that device when prompted.
